# ハヤト — Personal AI（Prototype 0.1）

iPhone・iPad向けの個人AIアプリの最初の画面・保存機能のプロトタイプです。

## 今できること
- チャット画面（現時点ではデモ応答）
- 会話履歴の端末内保存
- 知識・メモと出典URLの保存／削除
- タスクの追加・完了・削除
- 保存データからの簡易週間レポート作成
- PWA対応（対応ブラウザでホーム画面に追加可能）

## まだできないこと
- 本物のAIモデルとの会話
- 自動Web調査
- クラウド上の長期記憶・端末間同期
- アプリを閉じている間の定期実行
- プッシュ通知による週次報告

これらは次の段階でサーバー側のAI接続、データベース、スケジューラー、通知を追加して実装します。デモの返答をAIによる回答と誤認しないでください。

## GitHub Pagesで公開する手順
1. GitHubで新しい公開リポジトリ `hayato-ai` を作成します。
2. このZIPを展開し、中にあるファイルとフォルダをリポジトリの一番上（ルート）にアップロードします。`index.html` が最上位にある状態にします。
3. GitHubのリポジトリで **Settings → Pages** を開きます。
4. **Deploy from a branch** を選択し、Branchを `main`、フォルダを `/ (root)` にして保存します。
5. 公開URLが表示されたらiPhone・iPadのSafariで開き、共有メニューから「ホーム画面に追加」を選びます。

## 大切な注意
- このプロトタイプのデータは、利用しているブラウザの `localStorage` に保存されます。Safariと別ブラウザ、または別端末とは自動同期されません。
- ブラウザのデータ消去で保存内容が消える場合があります。大切な情報の唯一の保管場所にしないでください。
- APIキー、パスワード、個人情報をHTML・JavaScriptに書かないでください。GitHub Pages上のコードは公開されます。
- 外部フォント読み込みにはインターネット接続が必要です。フォントが読み込めなくても基本機能は動作します。

## 次の開発段階
1. サーバー側のAI API接続（キーはサーバーの環境変数に保管）
2. Supabase等による認証付きクラウド記憶
3. 情報収集ワークフロー（出典・日時・信頼性の記録）
4. 定期実行と週次レポート
5. 通知とユーザー承認フロー

自動実行は、許可したテーマ・情報源・頻度の範囲内に限定し、外部送信やデータ変更などの操作には確認を求める設計にしてください。
